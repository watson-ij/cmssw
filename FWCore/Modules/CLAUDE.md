# FWCore/Modules

## Purpose
Standard framework modules (output modules, event content analyzers, utility modules).

## Key Modules (Plugins)

Provides essential framework modules:
- Output modules for writing files
- Event content analysis modules
- Timing and profiling modules
- Debugging utilities

## Dependencies
- **FWCore**: Framework, ParameterSet, ServiceRegistry
- **DataFormats**: Common, Provenance
